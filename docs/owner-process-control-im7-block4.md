# IM-2026-000007 · Блок 4 · Решения по риску

## RU
Владелец → Главная → Управление процессами → Проверить назначения → открыть активное задание → Решение по риску. Выберите «Принять риск» или «Отозвать решение», введите обоснование 10–1000 символов и подтвердите. История содержит автора, дату, причину и редакцию; до пяти последних записей. Запись старой редакции не является подтверждением новой. Решение не разблокирует перевозку, не меняет документы, исполнителей, финансовые данные, результаты CI или права доступа. При конфликте обновите список. В других кабинетах права остаются неизменными.

## EN
Owner → Home → Process control → Check assignments → active task → Risk decision. Accept or withdraw the decision, supply a rationale of 10–1000 characters and confirm. The latest five decisions show author, date, rationale and task revision; an older revision does not approve the current one. This is an audit record, not a workflow, finance, access or release override. Refresh on a revision conflict. Other roles' permissions are unchanged.
