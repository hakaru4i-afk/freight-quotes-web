# IM-2026-000007 · Блок 7 · Восстановление заданий контрагентов
RU: Владелец → Главная → Управление процессами → Поставщики и дизайнеры. Раскройте задачу и выберите только доступное действие: переназначить, аннулировать, восстановить, вернуть завершённый комплект поставщику. Для переназначения выберите действующего сотрудника соответствующей роли. Укажите причину (10–1000 символов), подтвердите действие. Сервер сверяет редакцию и права. Аннулированные задания дизайнера не возобновляются при возврате документов. При конфликте обновите список. Завершение без обязательных документов и удаление через эту панель не допускаются.
EN: Owner → Home → Process control → Suppliers and designers. Open a task and choose a permitted action: reassign, cancel, restore or return a completed supplier package. Select an enabled recipient of the same role when reassigning. Enter a reason (10–1000 characters) and confirm. The server verifies identity and revision. Cancelled designer tasks are not reactivated by supplier return. Refresh after conflicts. No completion without required documents or deletion through this panel.
ZH: 所有者 → 主页 → 流程管理 → 供应商与设计师。展开任务并选择允许的操作：重新分配、取消、恢复或退回已完成的供应商文件。重新分配时选择相同角色的有效负责人。输入10–1000字符原因并确认。服务端检查身份和版本。退回文件不会重新激活已取消的设计任务。冲突时刷新列表。不得绕过必需文件完成任务，也不得通过此面板删除任务。
