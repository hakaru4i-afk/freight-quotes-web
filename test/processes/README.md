# Процессные схемы

Редактируйте `test/business-process-model.json`, затем выполните:

```
node scripts/build-process-maps.mjs --record-reviewed-sources
node scripts/build-process-maps.mjs --check
```

Первый вызов допустим после смыслового пересмотра согласованной логики: он фиксирует fingerprints отслеживаемых источников, не анализирует код автоматически. Генератор синхронизирует HTML, общую SVG, десять процессных схем, девять проекций кабинетов и страницы draw.io. CI отклоняет устаревшие файлы и источники без пересмотра.

TECH и LOGIC оцениваются отдельно. Предложения, требующие согласования, не добавляются как исполняемые этапы. Сохранена редакция 07.11 в `test/process-history/`; при новой существенной редакции сохраняйте прежнюю модель и схемы в истории до изменения канонических файлов. Git также сохраняет каждую версию.

Кабинеты ВЭД и логиста используют одну техническую роль `logistic`; это отражение действующей реализации, не новое объединение полномочий. Контент, дизайнер, закупки и сертификация не получают новых прав из диаграммы.
