# Freight Quotes Frontend

Действующий регламент описан в [правилах соответствия Production и Staging](docs/full-functional-parity-and-release-policy-20261117.md), порядок выпуска закреплён в [регламенте проверки пары](docs/locked-release-evidence.md).

- Сохраняйте доступность Production и согласованность фактических версий Frontend и API. Проверяйте исправления в изолированной среде. Публикуйте Production только через защищённый выпуск с подтверждением владельца.
- Используйте существующие раннеры, проверки и подтверждённые решения. Устраняйте первопричину, сохраняйте резервное копирование, восстановление и откат.
- Закрепляйте внешние Actions полным SHA и проверяйте их официальный runtime и вложенные вызовы. Обновляйте `.github/actions-runtime-lock.json` после проверки совместимости. Нативный runtime JavaScript Actions должен быть `node24`.
- Перед слиянием требуйте успешную проверку `Audit GitHub Actions runtimes`, целевые тесты затронутых контрактов и фактическую проверку результата. Сохраняйте ссылки на прогоны в текущей инженерной задаче.
