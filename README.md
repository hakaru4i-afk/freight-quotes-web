# freight-quotes-web
Публичные файлы интерфейса кабинета перевозчиков. Сервер и данные хранятся отдельно.

## Отчёт о проверках staging

[Обезличенный статус обновлений и приёмки](https://hakaru4i-afk.github.io/freight-quotes-web/test/qa-status.html). Полные реестры замечаний, разработок и обновлений доступны владельцу в **приватном** репозитории backend; необработанные QA-артефакты, документы, пароли и данные перевозок не размещаются на GitHub Pages. Изолированная проверка прав API обязательна перед признанием полного PASS.
